# Skills برای BEHIX Pro Engine

این پوشه مهارت‌های (Agent Skills) جمع‌آوری‌شده از مخازن متن‌باز را نگه می‌دارد تا Gemini / agentها برای کارگردانی، طراحی کاراکتر و انیمیشن از آن‌ها استفاده کنند.

## فهرست مهارت‌ها

| پوشه | منبع | کاربرد |
|------|------|--------|
| `cinematic-asset-prompts` | kangarooking/director-skills | تولید پرامپت دارایی سینمایی (کاراکتر، صحنه) |
| `emotion-performance-director` | kangarooking/director-skills | کارگردانی احساسات و عملکرد |
| `creator-generalist/` | codepawl/creator-generalist | مهارت‌های ۲D: طراحی، پس‌زمینه، انیمیشن |
| `fal-character-design` | fal-ai-community/skills | طراحی کاراکتر با ثبات هویت |
| `agent-character-design` | chunpu/agent-skills | طراحی کاراکتر (سه‌نما و مشخصات) |

## نحوه استفاده

این فایل‌های `SKILL.md` را به‌عنوان context یا system instruction به Gemini / Vertex AI بدهید تا خروجی‌ها یکدست و حرفه‌ای بمانند.
